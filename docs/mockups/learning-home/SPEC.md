# Learning Home — Clean Design

Status: planning baseline for mockups.

## Purpose
Learner-first entry for structured courses, due reviews and media-derived learning without exposing curriculum/admin internals.

## Page structure
Continue Learning -> Due Reviews -> Courses/Languages -> From Your Media -> Progress summary -> secondary tools.

## Data / information
LearnerCourse, current level/chapter/lesson, course progress, due review count/estimate, recent media contexts and compact mastery indicators.

## Actions
Continue course, start reviews, switch/add course, open media-derived items, open vocabulary/sentences/progress tools.

## Light / Dark
Both first-class; progress is compact and readable, not dashboard tile clutter.

## Platforms
Desktop/tablet: compact sections with optional two-column secondary content. Mobile: one-column, Continue/Reviews first. TV: only meaningful browse/review actions; detailed exercises may hand off.

## States
New learner/no course, course available, reviews due/none due, media library empty, offline deterministic course available, provider/AI unavailable, loading/error.

## Must not implement
No requirement for media to learn, no second SRS engine, no AI requirement, no admin curriculum controls, no duplicated media identities.
